# Getting help

* **Questions and usage**: GitHub Discussions of the repository, or the Neurostars forum
  with the tag `evoparam`.
* **Bugs**: the issue tracker, with the *Bug report* form and the output of `evoparam info`.
* **Ideas**: the *Feature request* form; **new presets** and **new datasets** have their
  own forms.
* **Security problems**: see [SECURITY.md](SECURITY.md).

The target is a median first response within 7 days. evoparam is maintained by its author
during 0.x (see [GOVERNANCE.md](GOVERNANCE.md)); please be patient.
