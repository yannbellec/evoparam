evoparam: evoked response parameterization
==========================================

evoparam (evoked response parameterization) parameterises evoked neural responses (CCEPs,
ERPs, SEPs, TEPs, ERNA, ECAPs, animal evoked potentials): each response becomes a small set of components with a latency, an
amplitude, a width and their uncertainty, a test of whether there is a response at all, and
a methods paragraph generated from what was run.

*For research use only: not a medical device.*
